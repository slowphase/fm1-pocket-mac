`pocket/policy.json` (95 approved, 23 excluded, 8 smoke exceptions, 0 withdrawn) leaves:

| | |
| --- | --- |
| 118 | RemoteFM1FW builds |
| −20 | marked † (restricted: contain material that may not be freely redistributed) |
| −2 | marked ‡ (fantasy builds for RemoteFM1's own apps, never FM-1 firmware) |
| −1 | h1, built into both players |

or a static screen), each documented in `smokeExceptions`. Open review or failure issues: 0.
