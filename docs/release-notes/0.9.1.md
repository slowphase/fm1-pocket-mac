# FM-1 Pocket 0.9.1

Unreleased. Preparing these changes does not publish a release or change the catalogue.

- Keep The Firmware Hub and RemoteFM1FW as the catalogue sources. Remove the FM1 Editor integration introduced during 0.9.1 preparation.
- Install a shared original package separately for each firmware ID. Argo and Felucca 8 Patterns already share the same package in the existing catalogue; both keep their own installation, playback and offline records.
- Improve release-preflight diagnostics: identify failed downloads by firmware, URL and error, and distinguish deliberately skipped alternative engines from missing installations.

Existing catalogue IDs, attribution, restrictions and user saves remain unchanged. No catalogue expansion is included.
